# 群星日程 · QunXing Schedule

> 一句话，千人千面 —— 每位你敬仰的人物，都是一颗星

互联网时代的产品满足所有人的共性需求；AI 时代，应用可以为每一个人生成。

**群星日程**是一款日程管理应用：日程功能所有人共用，而 App 的 Logo、背景、语录、配色，由你的一句话实时生成——说出你敬仰的那颗「星」，应用就为你点亮它的主题。

输入「我喜欢王阳明」，应用会换上水墨山水背景、《传习录》语录和印章 Logo；输入「我喜欢苏轼」，它会联网检索苏轼的真实名句，为他设计一套专属视觉，并生成一幅人物画像作为 Logo。

## 怎么用

应用分为两个页面：**「日程」**和**「主题定制」**。

### 📅 管理你的日程

在「日程」页，你可以：

- **新建日程**：点「新建日程」，填写标题、日期、时间和备注
- **四种方式查看全部日程**：
  - **列表**：按「今天 / 明天 / 未来」分组，就近排序
  - **日**：任意一天的日程时间线，可前后翻页
  - **月**：完整日历网格，有日程的日子显示标记，点日期看明细
  - **年**：12 个月总览，每月多少件事一目了然，点月份直达月视图
- **编辑 / 完成 / 删除**：点任意日程即可操作
- **设置提醒**：每条日程可选「准时 / 提前 5 分钟 / 提前 15 分钟」，到点弹出通知（首次使用请允许浏览器通知权限）

你的日程保存在浏览器本地，下次打开依然在。

### 🎨 一句话换主题

在「主题定制」页输入一句话，例如：

- 「我喜欢王阳明」
- 「我喜欢李白」
- 「我喜欢居里夫人」

应用会为这位人物实时生成专属主题：先联网检索他的**真实语录**（绝不编造），再设计配色、背景和字体，最后生成一幅人物画像作为 Logo。生成完成后一键套用，背景优雅淡入切换。

**主题画廊**里内置了三位大师——**王阳明、康德、尼采**，点卡片即可一键切换；你生成过的主题也会留在画廊里，随时换回。

页面顶部会显示当前主题的一句语录，点**「换一句」**可以手动切换。

## 常见问题

**什么样的话能生成主题？**
只支持真实人物：历史、哲学、文学、科学、艺术等领域的都可以。不支持娱乐圈明星和敏感人物，也不支持非人物（比如"我喜欢海边"）——这些会被礼貌拒绝并说明原因。

**语录是真的吗？**
是。非预设人物的语录全部来自实时联网检索，并标注来源网站；检索不到足够语录时会直接取消生成，宁可拒绝也不编造。预设主题的语录则取自《传习录》《实践理性批判》《查拉图斯特拉如是说》等真实著作，已剔除网络流传的伪托语录。

**生成次数有限制吗？**
没有。可以随意生成任意多个人物主题。

**换主题会影响我的日程吗？**
不会。主题只改变外观（背景、Logo、配色、语录），你的日程数据完全不受影响。
